# 🌤️ Weather App

A simple and user-friendly **Weather App** that allows users to search for a city and view its current weather information using the **OpenWeather API**.

## 📌 Features

* 🔍 Search weather by city name
* 🌡️ Display current temperature
* 💧 Display humidity
* 🌥️ Display weather condition
* 🌬️ Display weather-related information
* 🎨 Clean and simple user interface
* ⚡ Fetches real-time weather data using an API

## 🛠️ Technologies Used

* **Python**
* **OpenWeather API**
* **HTML**
* **CSS**
* **JavaScript**

## 🔑 API Key Setup

This project uses the **OpenWeather API**.

For security, the API key is **not included in this repository**.

Before running the project, add your own OpenWeather API key in the appropriate place in the code.

Example:

```text
YOUR_API_KEY
```

Replace `YOUR_API_KEY` with your own API key.

**Never share your personal API key publicly on GitHub.**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd Weather-App
```

### 3. Install required packages

If your project uses Python packages:

```bash
pip install -r requirements.txt
```

### 4. Add your API key

Add your OpenWeather API key where `YOUR_API_KEY` is mentioned in the project.

### 5. Run the application

Run the project using the appropriate Python file or open `index.html` in your browser, depending on your project setup.

## 💡 How It Works

1. The user enters the name of a city.
2. The application sends a request to the OpenWeather API.
3. The API returns the current weather information.
4. The application processes the response.
5. The weather details are displayed to the user.
